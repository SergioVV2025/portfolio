Proyecto real · En uso

Property Sheet Generator / Fichas

Aplicación web desarrollada para crear, administrar y publicar fichas inmobiliarias dentro de un flujo de trabajo real. El proyecto ha evolucionado conforme cambiaron las necesidades de uso, especialmente la forma en que las propiedades se consultan y comparten desde móvil.

Qué resolví

Rediseñé la entrega de la ficha para priorizar fotografías y lectura rápida, incorporando galería táctil con precarga de imágenes, características principales con iconos, amenidades, contacto directo por WhatsApp, datos del agente y ubicación integrada con Google Maps.

Por qué importa

Automatiza una tarea repetitiva, mantiene una presentación consistente entre propiedades y genera páginas HTML listas para publicar y compartir, incluyendo metadatos Open Graph.

Full Stack · Proyecto reciente

Saade Full Stack

Aplicación full stack para Saade, un restaurante en Silver Lake, Los Ángeles. El proyecto evolucionó de una interfaz conectada a una API externa a una aplicación con backend propio, autenticación, persistencia de datos y operaciones protegidas por usuario.

Qué implementé

Registro e inicio de sesión, persistencia de sesión con JWT, rutas protegidas y flujo CRUD de reservaciones: crear, consultar, editar y cancelar. El backend valida que cada reservación pertenezca al usuario autenticado antes de modificarla.

Integración y producción

React y Vite en frontend; Node.js, Express, MongoDB y Mongoose en backend. También integra Ticketmaster Discovery API y está desplegado con Nginx, PM2 y HTTPS mediante Let's Encrypt.

React · Vite · React Router · JavaScript · Node.js · Express · MongoDB · Mongoose · JWT · bcrypt · REST API
